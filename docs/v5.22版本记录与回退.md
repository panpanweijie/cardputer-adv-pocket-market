# v5.22 扫描驱动参数初始化修复

## 直接代码证据

当前构建Arduino ESP32 2.0.16的WiFiScan.cpp使用未清零的wifi_scan_config_t局部变量，赋值已知字段后传给esp_wifi_scan_start；配套ESP-IDF结构已经包含home_chan_dwell_time，但此字段未赋值，会传入不确定的字节。

## 最小修复

将官方WiFi库保存在lib/WiFi，保留原许可证与归属；仅把扫描结构初始化为{}，显式设置home_chan_dwell_time=30ms。PlatformIO优先使用项目本地库；未修改全局框架缓存。其他扫描控制参数保持v5.21，新增串口扫描结果诊断（不输出SSID/密码）。

## 验证与边界

- test_wifi_driver_config.py直接提取并运行实际WiFiScan.cpp函数，使用编译器pattern填充未初始化栈。旧代码对照组传入非30值，返回42；修复组通过。它证明驱动缺陷可复现，不证明该字段就是用户设备全部扫描故障的唯一原因。
- test_wifi_runtime.cpp执行实际应用扫描代码，覆盖保持已连接、离线、R防重复、失败/超时有限重试及取消恢复。
- 两种构建的WiFiScan.cpp.d均指向lib/WiFi/src/WiFiScan.cpp，确认修复编入固件；两环境编译和镜像校验通过。
- 未在设备上验证扫描恢复；不宣称已经实机修好，也不归咎硬件。
