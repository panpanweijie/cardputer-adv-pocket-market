# 手机管理与搜索

## 手机网页

设备与手机连接同一个可信 Wi-Fi；设备首页 / 详情按 W，手机扫描屏幕二维码。网页在设备本地提供，仅打开二维码页时运行。

网页可选常用股票组合、按市场添加、批量粘贴代码；带 us / hk / sh / sz 前缀的代码可以混合导入。未带前缀时，先选择对应市场。示例：美股 AAPL；港股 700；A 股 600519 / 300750。

我的自选中，按住左侧 ≡ 拖动排序；电脑也可聚焦手柄按上下键排序。删除或排序只改待保存列表。点底部“保存到设备”才替换完整自选；底部固定栏会显示保存中 / 成功 / 失败。保存期间暂不可编辑，避免写入顺序不一致。设备退出后服务关闭。

## F 搜索

- 代码：TAB 切 EN，输入 BMNU、AAPL 等，Enter 查询。
- 常用拼音别名：CN 输入 `kekokele` 或 `kkkl`，Enter 可命中 KO（可口可乐）；COKE 是装瓶商，另列结果。
- 常用字词：输入拼音，1 / 2 / 3 选词；空格选首候选；可连续选词组成查询，再 Enter 搜索。
- 未命中本地索引会在线查询；本地词库可以离线输入 / 查常用项，报价和全市场在线查询需要网络。
- 结果用 ; / . 选择，Enter 加入并保存；已在自选的股票不会重复加入。
- 美股搜索返回的 .AM / .OQ / .N / .O / .PS / .PK 路由后缀会清理；真实类别后缀 BRK.A / BRK.B 保留，图表使用独立交易所标识。

候选和结果有数量上限以控制内存，不能用来推断全市场覆盖。无声调、通用中文联想或完整汉字词库。


## v5.23 自选名称

排序区显示“代码 · 名称”。常用股票优先中文名，其他股票使用设备已缓存名称；尚无名称时仅显示代码。名称只用于展示，保存与排序仍使用唯一代码。升级后重新扫码或刷新网页。
