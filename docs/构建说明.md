# 构建说明

使用 Python 3、PlatformIO Core，进入项目根目录：

```sh
pio run -e stock-monitor
pio run -e stock-monitor-standard
```

产物位于 `.pio/build/<环境>/firmware.bin`，是 **0x10000 应用文件**，不是完整安装包。

当前配置：Espressif32 6.7.0 / Arduino ESP32 2.0.16 / ArduinoJson 6.21.5。M5Cardputer 来自官方 GitHub，当前公开构建基于 f1392858b9994c3547120e602a57d3553d16ab01，M5GFX 0.2.33；依赖未来 HEAD 可能改变，重现时请核对版本。

`tools/public_build.py` 把本机用户名 / 项目路径映射为中性编译路径，避免诊断字符串泄露本机路径；不改变运行行为。`tools/embed_phone_page.py` 在构建前将手机 HTML 同步到固件。

修改词库后运行：

```sh
python3 tools/generate_pinyin.py
python3 tools/generate_stock_aliases.py
python3 tools/embed_phone_page.py
```

`src/` 为 PlatformIO 源码；`arduino/stock_monitor/` 为同步 Arduino IDE 入口，需要自行安装同等依赖，公开构建使用 PlatformIO 验证。源码改动后也应同步该目录。

完整安装镜像由 ESP32-S3 引导（0x0）、分区表（0x8000）、空白 NVS（0x9000）、OTA 初始化（0xe000）和应用（0x10000）合并，不从设备导出 Flash。发布包附有安装清单与 SHA256。

## 本地WiFi库必须保留

项目lib/WiFi包含与框架2.0.16兼容的官方库修复副本，仅修正扫描参数初始化。不要删除lib目录。Arduino IDE需要额外安装该修复库；仅复制arduino入口而使用原未修复WiFi库不等价。库为LGPL-2.1-or-later，保留源码、修改记录及LICENSE-LGPL-2.1.txt / LICENSE-GPL-2.0.txt。
