# 全部按键（v5.22）

按键名称按设备标识。普通字符别名无需 Fn；需要输入符号 + 时可直接用 Z 替代。长按连发仅用于首页 / 卡牌，不适用于所有菜单。

| 场景 | 按键 | 动作 |
| --- | --- | --- |
| 所有页面 | ESC（也兼容反引号） | 返回上一层；普通首页为根页面，无操作 |
| 非输入页面 | B | 关屏 / 亮屏，恢复所设亮度；不休眠、不停止联网 |
| 首页 / 详情 | 侧面 BtnA | 手动刷新，与 U 相同；其他页面不执行刷新 |
| 普通首页 | 1 / 2 / 3 | 当前屏第 1 / 2 / 3 只的详情 |
| 普通首页 | 上 / 下，或 ; / .，或 , / / | 滚动；短按单步，长按约 350ms 连发，约 1.5 秒后加速 |
| 普通首页 | Enter | 编辑完整自选代码列表 |
| 首页（列表 / 卡牌） | TAB | 设置 |
| 首页 / 详情 | F | 股票搜索 |
| 首页 / 详情 | W | 手机管理二维码 |
| 首页 / 详情 | U | 手动更新当前报价；详情同时尝试更新图表 |
| 首页，motion 版 | G | 开启 / 关闭体感卡牌模式 |
| 卡牌 | 左 / 右，或 , / / | 选卡；短按微调，长按连续滑动并加速 |
| 卡牌 | ; / . | 兼容选卡字符键 |
| 卡牌 | Enter | 打开当前卡牌详情；1 / 2 / 3 不操作 |
| 卡牌 | ESC | 关闭体感并回到普通列表 |
| 详情 | TAB | 5D → D-K → W-K → M-K → Y-K 循环 |
| 详情 | Space | K 线 / 收盘价折线切换，5D 保持线图 |
| 详情 | Z、+ 或 = | 放大，减少可见点 / K 线数量，通常最少 5 根 |
| 详情 | X、- 或 _ | 缩小，增加可见数量，上限为已缓存数据 |
| 详情 | ; / , | 上一只股票，首尾循环 |
| 详情 | . / / | 下一只股票，首尾循环 |
| 详情 | D | 进入删除当前自选的确认页 |
| 删除确认 | Enter | 确认删除并保存；其他字符不能确认 |
| 删除确认 | ESC | 取消，回到详情 |
| 手工代码编辑 | 普通字符 | 编辑英文逗号分隔的完整列表 |
| 手工代码编辑 | DEL | 删最后一个字符，无需 Fn |
| 手工代码编辑 | Enter / ESC | 保存 / 放弃返回 |
| 设置 | ; 或 , / . 或 / | 上一项 / 下一项 |
| 设置 | Enter | Wi-Fi 进入扫描；其他项切换选项 |
| Wi-Fi 扫描 | ; 或 , / . 或 / | 选择上一 / 下一网络 |
| Wi-Fi 扫描 | R | 重新扫描，断网也可使用 |
| Wi-Fi 扫描 | Enter | 为选中网络输入密码 |
| Wi-Fi 密码 | 普通字符 / DEL | 输入 / 删除末尾字符，DEL 无需 Fn |
| Wi-Fi 密码 | Enter | 保存并尝试连接，回到首页 |
| Wi-Fi 密码 | ESC | 放弃输入，回到扫描页 |
| 搜索 | TAB | CN 拼音 / EN 英文模式切换，未转换字母保留 |
| 搜索 | 字母 / 数字 | 输入；CN 模式字母先进入拼音组合 |
| 搜索拼音组合 | 1 / 2 / 3 | 选择当前页对应候选词 |
| 搜索拼音组合 | Space | 选择当前页第一个候选词 |
| 搜索拼音组合 | ; 或 , / . 或 / | 候选上一页 / 下一页 |
| 搜索 | Enter | 已命中完整别名时直接查询；否则先提交拼音首候选，再按 Enter 查询；有结果时加入所选股票 |
| 搜索结果 | ; 或 , / . 或 / | 上一 / 下一结果，最多显示 8 个结果 |
| 搜索 | DEL | 清结果后编辑；优先删拼音，否则删一个完整 UTF-8 字符 |
| 搜索 | ESC | 退出并放弃未完成输入，回到原首页 / 详情 |
| 手机二维码页 | ESC | 关闭本地网页服务，回到原页面 |

输入页中 B / F / G / U / W 是普通输入字符，不触发对应全局功能。ESC 先由统一导航处理。网络同步请求期间可能有短暂停顿。

## 设置选项

1. Wi-Fi：选择 / 扫描 / 输入密码。
2. Refresh：5 秒、10 秒、30 秒、60 秒、5 分钟循环；后台预载与盘前有独立调度，不承诺全列表按此频率更新。
3. Brightness：20%、40%、60%、80%、100% 循环。
4. Time zone：中国 / 香港、纽约、东京、伦敦、UTC；默认北京时间，手动选择。纽约、伦敦按规则处理夏令时。
5. Motion：motion 版可切换；standard 不显示。

## 返回层级

删除确认 → 详情 → 原列表 / 卡牌；卡牌 → 普通首页。

搜索 / 手机管理 → 打开前页面；代码编辑 → 首页；Wi-Fi 密码 → 扫描 → 设置 → 首页。普通首页 ESC 无操作。

## v5.22 Wi-Fi 列表

网络名称使用中文字库，按完整 UTF-8 字符截短显示，不改变连接使用的完整名称。相同名称合并并保留最强信号，按信号从强到弱排序；右侧显示 dBm，数值越接近 0 信号越强（例如 -45 强于 -75）。空名称合并为一个“隐藏网络”入口，Enter 后先填准确 SSID，再 Enter 填密码；SSID 为大小写敏感，当前键盘手输支持 ASCII 字符，不提供中文 SSID 输入法。ESC 退出到扫描页。不再固定截取前20个结果，仍受扫描驱动和可用内存限制。仅支持 2.4GHz，纯 5GHz 网络不会出现。R 可重扫。
