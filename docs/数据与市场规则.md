市场状态结合联网状态字段、本地交易时间与已知当日信息判断。美股使用纽约当地时区及夏令时；沪深 / 港股按当地时段处理，包含午休与竞价差异。接口失效时按时段回退并保留已知当日休市 / 提前收盘信息；这不等同于完整交易所日历，也不保证识别每只股票临时停牌。

列表不重复写每股“交易 / 休市”。有效主价在交易 / 竞价时亮色，其余时段灰色；详情 / 卡牌显示当前股票市场状态。橙点只表示异常：交易时报价日期旧、时间缺失、延迟超过约 5 分钟，或盘前抓取失败 / 无效。v5.22 不再因为最后盘前成交超过 15 分钟而亮橙点。Wi-Fi 图标只反映路由器连接。

盘前仅接收明确标为 before 的数据；拒绝错误会话、未来时间、缺失涨跌幅的后台结果，开盘后隐藏盘前行。免费数据可能未覆盖某股盘前交易，不能据此证明没有成交。

公共数据接口可能变动、限流或中断。本工具仅展示信息，不连接券商、不下单、不承诺交易级实时。
