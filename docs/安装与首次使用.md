# 安装与首次使用

## 首次完整安装

1. 确认设备是 Cardputer ADV，准备支持数据传输的 USB 线。
2. 使用桌面 Chrome / Edge 打开 https://burner.m5stack.com/device/cardputer-adv 。固件正式上架后，在 Cardputer ADV 分类搜索 Pocket Market，核对版本和设备再连接、烧录。本包当前未上架，不能保证现在能搜到。
3. 本地安装可使用 https://espressif.github.io/esptool-js/ ，连接设备串口，选择 motion-full-0x0.bin，地址 **0x0**。standard-full 同地址。
4. 完整镜像包括引导、分区和应用，写入范围内配置区域为空白；会覆盖原有 Wi-Fi、自选设置。它面向首次安装 / 更换其他固件，不用于保留配置的升级。
5. 完成后重启。无串口时检查数据线；必要时按设备方式进入下载模式后重新连接。

## 已有本项目的升级

1. 必须是本项目兼容分区布局（app0 0x10000 / app1 0x340000）的设备。
2. 使用对应 update-0x10000.bin，地址 **0x10000（65536）**。
3. **不要 Erase All Flash**。同布局升级保留 Wi-Fi、自选与设置。
4. 从未知固件 / 未知分区迁移时使用完整安装，不保证保留其数据。

## 第一次配网

1. 首页按 TAB，选择 Wi-Fi 后 Enter。
2. 离线也能扫描。用 ; / . 选择，R 重扫，Enter 输入密码。
3. 直接 DEL 删除，Enter 保存连接。ESC 可逐层返回。
4. 顶部 Wi-Fi 蓝色说明已连路由器；若行情未出现，检查该网络能否访问行情服务，再按 U。

## 建立自己的自选

- 最方便：W → 手机同 Wi-Fi 扫二维码 → 批量导入 / 选择股票 → ≡ 拖动排序 → 底部保存到设备 → 成功后设备 ESC 返回。
- 设备直接添加：F → 输入代码 / 拼音搜索 → ; / . 选择 → Enter 加入。
- 批量手输：首页 Enter，使用英文逗号分隔，如 `usAAPL,hk00700,sh600519,sz300750`，Enter 保存。

普通首页用 1 / 2 / 3 查看当前行详情；TAB 换图表周期，空格换线图，Z / X 缩放。G 开卡牌，左右倾斜选股，Enter 看详情，ESC 返回。

## 常见情况

- 没有报价：U 重试；新股票预加载需要时间。
- 图表提示 Press U to refresh：数据源未成功返回图表，按 U 重试；报价正常不保证图表接口正常。
- 美股休市主价灰色：表示非交易时段，仍可阅读最后常规报价。
- 橙点：报价 / 盘前获取异常，不是涨跌提示；盘前长期无成交本身不算异常。
- 手机打不开：保持二维码页，确认同一局域网且路由器未启用客户端隔离；不是公网地址。
- 退出二维码页后网页不可保存：该页退出即关闭服务，再按 W 重新打开并扫码。
- 体感手感不合适：G / ESC 退出；也可安装 standard 同布局升级包，保留其他功能。

## v5.22 Wi-Fi 列表

网络名称使用中文字库，按完整 UTF-8 字符截短显示，不改变连接使用的完整名称。相同名称合并并保留最强信号，按信号从强到弱排序；右侧显示 dBm，数值越接近 0 信号越强（例如 -45 强于 -75）。空名称合并为一个“隐藏网络”入口，Enter 后先填准确 SSID，再 Enter 填密码；SSID 为大小写敏感，当前键盘手输支持 ASCII 字符，不提供中文 SSID 输入法。ESC 退出到扫描页。不再固定截取前20个结果，仍受扫描驱动和可用内存限制。仅支持 2.4GHz，纯 5GHz 网络不会出现。R 可重扫。
