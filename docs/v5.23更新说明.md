# v5.23 体感版

手机自选排序行显示“代码 · 名称”，与常用列表一致。常用股票优先中文名，其他股票使用设备缓存名称 / 内置别名，尚无名称时只显示代码。名称只用于展示，保存仍发送代码，排序与删除行为保持一致。网页使用 textContent 展示名称，不将名称作为 HTML 执行；打开页面不增加行情请求。

老用户用 motion-update-0x10000.bin 写入 0x10000，不清空 Flash。M5Burner 首次安装用 motion-full-0x0.bin，地址 0x0，会覆盖配置。升级后退出并重新进入扫码管理页，手机重新扫码 / 刷新。

验证：网页名称、未知代码回退、排序、取消、保存成功 / 失败、导入测试通过；沿用 v5.22 硬件依赖，体感版构建通过，完整包分区合并及应用一致性检查通过。未进行真机烧录。
